💻 GitHub Repository: https://github.com/loomlogic01/myshowcase-portfolio

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/loomlogic01/myshowcase-portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd myshowcase-portfolio
   ```

3. Open `index.html` in your browser, or use the VS Code Live Server extension.
